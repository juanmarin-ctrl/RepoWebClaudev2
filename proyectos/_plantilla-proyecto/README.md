# Proyecto: (nombre del cliente)

Esta carpeta es la **estructura de referencia** que usa Claude. No hace falta copiarla a mano: crea una carpeta con el nombre del cliente en `proyectos/`, copia ahí su material y pide *Crea la web de <cliente>*.

Claude deja en la carpeta del cliente:
- `brief/`: el material ordenado y `_normalizado.md`;
- `concepto.md`: la idea de la web;
- `mockup/`: la maqueta;
- `payload/` y `site-maestro.zip`: la web lista para WordPress.

## Checklist (la completa Claude)

- [ ] concepto.md con el test anti-template
- [ ] Maqueta aprobada
- [ ] Payload y ZIP
