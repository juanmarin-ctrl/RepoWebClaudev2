# Brief

**Lo normal:** copia el material del cliente en `proyectos/<cliente>/` y pide a Claude *Crea la web de <cliente>*. Claude lo ordena solo.

**Bandeja rápida:** si aún no sabes cómo se llama el proyecto, suelta los archivos en `brief/entrada/` y dile a Claude *Crea la web con lo que hay en brief/entrada*.

Las plantillas de `brief/plantillas/` son la guía de lo que Claude busca en el material:
- empresa;
- acerca;
- oferta;
- branding;
- imágenes.

No hace falta rellenarlas.
